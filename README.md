## Summary

> [Return to Table Of Contents](#table-of-contents)

The Harpy repository is in the early stages of development, focusing on
the specification and foundation of a programming language designed for
execution security and performance.

The language implements _Design by Contract_ mechanisms, a
_strong type system_, and _declarative metadata_, featuring a syntax
designed for readability and structural clarity. From an architectural
perspective, Harpy introduces Pangaea as its compilation model.

The current codebase is in its early stages, with development focused on
building the [Compiler Support Library](./library/README.md) and the
backend architecture; specifically, the implementation of the
_tripartite allocation system_.
